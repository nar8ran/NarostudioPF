# Cyber Nurse サイト — 編集ガイド

素の HTML / CSS / JS だけで動きます（ビルド不要）。
`cyber-nurse/index.html` をブラウザで開けばそのまま表示できます。

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | TOP（映像ヒーロー＋コンセプト＋ナビ） |
| `character.html` | Cyber Nurse（プロフィール・立ち絵・三面図・配布） |
| `usage.html` | 使い方（導入手順・楽しみ方） |
| `terms.html` | 利用規約（許諾・禁止・免責・その他） |
| `style.css` | デザイン（配色はここの `:root` を変更） |
| `script.js` | メニュー開閉・映像再生・スクロール演出 |

## よくある編集

### 1. 配色を変える
`style.css` 冒頭の `:root` にある `--pink-*` などを書き換えるだけで全ページに反映されます。

### 2. 立ち絵・三面図・表情差分を入れる（character.html）
`assets/` フォルダを作って画像を置き、`<div class="ph ...">` を `<img>` に置き換えます。
```html
<!-- 例：立ち絵 -->
<img src="assets/tachie.png" alt="Cyber Nurse 立ち絵"
     style="border-radius:var(--radius-lg)" />
```

### 3. TOP に映像を流す（index.html）
`movie/` フォルダを作って動画を置き、ヒーロー内のコメントアウトされた
`<video class="hero__video" ...>` を有効化して `src` を差し替えます。
※ 自動再生には `muted playsinline` が必要です。src が無いときはアニメ背景が出ます。

### 4. モデル配布リンク（character.html）
「ダウンロード」ボタンの `href="#"` を、BOOTH などの配布先 URL に変更してください。

### 5. SNS リンク（各ページのフッター）
`X (Twitter)` の `href="#"` を実際のアカウント URL に変更してください。

### 6. 文章の書き換え
プロフィール・カルテの値・使い方の手順・利用規約は、
各 HTML 内のコメント（`<!-- ▼ ... -->`）を目印に自由に書き換えられます。
